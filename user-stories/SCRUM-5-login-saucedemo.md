# SCRUM-5: Login SauceDemo

## Story Title
As a user, I can log in with valid credentials

## Story ID / Link
- ID: SCRUM-5
- Jira URL: https://sudharanimsc.atlassian.net/browse/SCRUM-5
- Application URL: https://saucedemo.com

## User Story
As a registered SauceDemo user,
I want to log in with a valid username and password,
so that I can access the product catalog.

## Acceptance Criteria
- Given I am on the login page
- When I enter "standard_user" / "secret_sauce"
- Then I am redirected to the products page
- And I see the page title "Products"

## Notes
- Priority: Medium
- Work type: Story
- Status: To Do
- Project: AIDemo

## Summary
This story covers the standard SauceDemo login flow for a registered user. The user must be able to log in with a valid username and password and land on the Products page after successful authentication.
